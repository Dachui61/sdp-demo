SOCKS5 代理工作原理图示

1. 正常网络连接（无代理）:
    
    +----------------+        +------------------+
    |   应用程序     | -----> |   目标服务器     |
    | (浏览器等)     | <----- | (网站等)         |
    +----------------+        +------------------+
          ↑                          ↑
          |                          |
          +---- 直接连接 ------------+


2. 使用 SOCKS5 代理的连接:

    +----------------+        +------------------+ 
    |   应用程序     | -----> |  SOCKS5 代理      |
    | (浏览器等)     | <----- |  (client.exe)     |
    +----------------+        +------------------+ 
                                    ↑
                                    |
                              +------------------+
                              |   gRPC 隧道      |
                              |   (安全通道)     |
                              +------------------+
                                    ↑
                                    |
                              +------------------+        +------------------+
                              |   网关服务器      | -----> |   目标服务器     |
                              |  (gateway.exe)   | <----- | (网站等)         |
                              +------------------+       +------------------+


3. 详细数据流向:

步骤 1: 应用程序发起连接
    [应用程序] --"我想访问 http://example.com"--> [SOCKS5代理 127.0.0.1:1081]

步骤 2: SOCKS5 代理处理请求
    [SOCKS5代理] --"通过gRPC隧道发送请求"--> [网关 :50051]

步骤 3: 网关访问目标服务器
    [网关] --"直接连接到 http://example.com"--> [目标服务器]

步骤 4: 目标服务器响应
    [目标服务器] --"返回网页内容"--> [网关]

步骤 5: 通过隧道返回响应
    [网关] --"通过gRPC隧道返回响应"--> [SOCKS5代理]

步骤 6: 返回给应用程序
    [SOCKS5代理] --"返回网页内容"--> [应用程序]


4. 端口和地址说明:

    组件          地址            端口        功能
    -----------------------------------------------------
    客户端        127.0.0.1      1081        SOCKS5 代理服务
    网关          0.0.0.0        50051       gRPC 监听
    网关测试后端  0.0.0.0        9000        测试用 HTTP 服务
    本地测试服务  127.0.0.1      8080        本地 HTTP 服务


5. 日志信息说明:

    客户端日志:
    - "Starting SOCKS5 server on 127.0.0.1:1081" 表示 SOCKS5 代理已启动
    
    网关日志:
    - "gRPC listening :50051" 表示网关正在监听 gRPC 连接
    - "new gRPC tunnel stream established" 表示新的隧道连接已建立
